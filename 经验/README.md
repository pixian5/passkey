# pass 经验库

把 `docs/` 里的过程记录压成「下次动手前能五分钟查完」的结论。只收还能指导行动的内容：**现象/触发条件 → 根因 → 正确做法 → 出处**；不复述更新日志、不堆版本号流水账。

> `docs/` 是过程记录，可能过时甚至写错；本目录是当时的结论；**冲突时以代码与最新实测为准**。
> 标注约定：`【已验证】` 有单测/实测闭环；`【推测】` 合理但未闭环，落地前先做小实验；`已推翻` 保留旧结论并给出新结论。

## 维护

- 代码修复推翻旧结论时，不要删除旧条目，改为「已推翻：<新结论>」，避免下次又踩同一个坑。
