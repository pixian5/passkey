# 三端同步契约与合并

> 适用范围：Tauri 桌面 / Docker Web / Chrome 扩展 / 自建同步服务。
> 阅读前提：`docs/` 是过程记录，可能过时；**冲突时以代码与最新实测为准**。
> 本文只保留「下次动手会用到」的结论，版本流水账见 `docs/`。

## 1. revision 变了不等于内容变了：LOCAL_CHANGED 误报要三层修

**现象**：同步推送已成功，收尾仍红字报 `LOCAL_CHANGED`；每次同步都失败，换同步编号重试也一样。
**根因**：并发守卫只比较业务 `businessRevision`，而同步窗口内存在「同内容等价重写」把 revision 顶掉 +1：
- Web 桥回显 `handleWebBridgeSyncData` 无条件 `setAllDataToDataStore`（无等值守卫、无 expectedRevision）；
- 管理页 `extension-bridge.js` 的 `normalizeData` 会实质改写内容（覆盖 `lastOperatedDeviceName`、回填 `xxxUpdatedAtMs`、过滤并重排 `folderIds`/排序数组），这些差异能穿过后台 `normalizeSyncPayloadShape`。

**正确做法（三层，缺一层仍可能复现）**：
1. **等值守卫**：回显落库前先与当前库做 `syncPayloadEquals`，一致则直接返回 ok，不落库不推进 revision。
2. **同步窗口写闸门**：`runManagedSync` 全程开窗，`handleWebBridgeSyncData` 落库前 `await waitSyncWindowEnd()`；窗口内回显推迟到同步结束。
3. **广播即发即忘**：`broadcastWebBridgeData` 不再 `await` 页面 ack，只 `.catch` 吞「页面未开」。否则形成 同步→等广播 ack→页面 persist→回发回显→等窗口结束→同步 的三方死锁，「正在同步…」永久不结束。

**判据**：LOCAL_CHANGED 报错应自带 `版本 A→B；账号 X→Y / 首差异样例 / 排序表不同 / 设备名不同`；若仍报，才是真实并发编辑。
**已推翻**：1.8.9 曾把该报错解释为「良性措辞问题」——不成立，它是确定性缺陷。
**出处**：`docs/20261013-1243-同步LOCAL_CHANGED等价重写误报根治-Hy3.md`、`docs/20261013-1305-同步LOCAL_CHANGED同步窗口写闸门与判决诊断-Hy3.md`、`docs/20261013-1315-同步卡死广播回显同步窗口三方死锁修复-Hy3.md`

## 2. 永久墓碑护栏必须按同步模式区分

**现象**：点「云端覆盖本地」被 `PERMANENT_TOMBSTONES_DROPPED[accounts:dropped=163… mode=remoteOverwriteLocal]` 永久拦死。
**根因**：护栏不分模式，统一要求 `required = 本地墓碑 ∪ 远端墓碑`；覆盖模式本就按用户显式选择丢弃本地侧独有墓碑。
**正确做法**：
- `merge`：两端全保留；
- `localOverwriteRemote`（也是 WebDAV 镜像上传模式）：两端全保留，镜像必须忠实反映删除，否则旧设备会复活数据；
- `remoteOverwriteLocal`：只要求保留**远端**墓碑；仅当远端墓碑本身丢失才拦。
JS（`core/pass_core/js/sync_merge_core.js`）与 Rust（`crates/merge/src/v2/safety.rs`）必须同步改，否则对拍会漂移。
**出处**：`docs/20261013-1201-云端覆盖本地墓碑护栏误拦修复-Step-5-Preview.md`、`docs/20260930-0048-同步补偿对账与服务器认证加固-GPT-6.md` §2.3

## 3. 内置「新账号」文件夹不能强制复活

**现象**：merge 模式报 `PERMANENT_TOMBSTONES_DROPPED`，每次必现。
**根因**：`mergeSameFolder` 对固定文件夹（`FIXED_NEW_ACCOUNT_FOLDER_ID`）有特例：两侧都有该文件夹时无条件写 `isPermanentlyDeleted: false`，把远端墓碑「复活」；护栏随后发现 required 中的墓碑不在 merged 里。
**正确做法**：固定文件夹分支与普通文件夹分支行为一致，尊重已算好的 `keepPermanentlyDeleted/keepDeleted`；JS 与 Rust 同步修，并加「远端墓碑 + 本地活跃」回归用例。若产品上不想允许删除，应在删除入口拦截，不要在合并里强制复活。
**出处**：`docs/20261013-0935-固定文件夹墓碑复活触发永久删除护栏拦截缺陷修复-Step-5-Preview.md`

## 4. 并发写入按 ETag/If-Match + 幂等键，失败必须能收敛

**契约要点**：
- 更新已有状态必须带 `If-Match`；缺失返回 `428`，过期返回 `412`。客户端遇 412/428 统一「拉取 → 合并 → 用新 ETag 重试」。
- 每次逻辑写入一个 `Idempotency-Key`；**键必须与请求体摘要绑定**。信封里的 `exportedAtMs`、AES-GCM nonce 每次都会变，重试若换体又复用旧键，会得到 `IDEMPOTENCY_KEY_REUSED`。
- PUT 结果不确定时先回读远端：业务载荷一致即按成功收敛，不重复建历史版本。
- 冲突后回读失败也必须结构化返回 `pendingRetry`，否则「本地已写、远端未写、outbox 为空」会永久漏账。
- outbox 只在当前本地 payload 摘要与入队时一致时复用幂等/会话上下文；内容一变就是新的逻辑写入，换新键。
- 自动重试 12 次（5/10/20/40/80/160/320/640/1280 秒）；第 12 次失败进入 `paused`，定时器不得再自动重试，必须用户点「立即重试补偿任务」。
- target 键要规范化 host 大小写、默认端口、尾部斜杠，否则同一服务器会产生多条重试记录。
- 服务端 `X-Sync-Revision` 是 **scope 内**单调计数，`version_id` 是全局历史行 ID；每 scope 最多 50 个版本、5000 条审计。
**出处**：`docs/sync-protocol-v2.md`、`docs/20260930-0048-同步补偿对账与服务器认证加固-GPT-6.md`、`docs/test-baseline-and-sync-e2e-zh.md` §4

## 5. 安全闸门的硬规则

- 远端空包**永远不能**覆盖非空本地；所有本地稳定 ID（account/folder/passkey）必须在合并结果里存在，否则拒绝写入。
- 永久删除墓碑保留在 payload 与身份集合中（防止旧客户端复活），但不计入用户可见数量、预览与导出摘要。
- 数据库/密钥不匹配是致命错误：不得新建替代密钥，也不得回退到更小的旧数据集。
- 恢复必须同时保留 `pass.db`、`pass.db-wal`、`pass.db-shm`。
**出处**：`docs/sync-protocol-v2.md`「Safety and recovery」、`docs/cross-platform-sync-backends-v2-zh.md` §4

## 6. WebDAV 与自建服务器的能力边界不同

- WebDAV 只有 ETag/If-Match，**没有**版本列表、审计、恢复；不要按自建服务器的能力写 UI。
- 远端已有非空包但**没有 ETag** 时，必须拦截并报错，不能退化成无条件覆写。桌面与 Docker Web 的 `require_etag_for_existing` 契约要一致。
- Chrome 在后台 Service Worker 发 WebDAV 请求（靠 manifest host permission 跨域），管理页只提交设置与一次同步意图；`sync_webdav_now_mode` 也委托同一个后台入口，不得启动第二个同步引擎。
- Chrome 后台一次处理全部启用来源，声明 `managedMultiSourceSync: true`，共享 UI 只调用一次 `sync_now_mode`。
**出处**：`docs/cross-platform-sync-backends-v2-zh.md` §3–4、`docs/20261104-1125-当前开发进度-antigravity.md` §2

## 7. 同步地址不允许「静默改写」

**现象**：扩展与 macOS 填 `https://or.sbbz.tech:5443`，实际打到了默认服务器 `uk.sbbz.tech:5443`。
**根因**：`normalizeLegacySelfHostedServerBaseUrl`（扩展）与 `normalizedSelfHostedServerBaseURL`（Swift）里残留调试分支：`host === "or.sbbz.tech" && port === 5443` 就返回默认地址；Tauri Rust 没有这段，所以只有桌面端正常。
**正确做法**：删掉硬编码改写，只保留 `127.0.0.1/localhost:53333` 历史本地映射；源与 `apps/extension_chrome_web/dist` 必须一起重建。同类问题优先查「地址归一化函数」而不是网络。
**出处**：`docs/20261013-0349-扩展与macOS同步URL改写缺陷修复-Step-5-Preview.md`

## 8. 单写实例：锁文件只是诊断，不是判据

- Docker Web 打开 `/data/pass-web-instance.lock` 后持内核排他锁；PID/nonce 只用于诊断。
- 正常退出、`SIGKILL`、容器崩溃都会由内核释放锁；**遗留锁文件不会阻止新实例**，恢复步骤里不要写「删锁文件」。
- 新实例仍报占用，说明确有另一个进程持锁：停掉挂同一 named volume 的旧实例，再启动并查 `/healthz`。
**出处**：`docs/sync-protocol-v2.md`「Docker 容器替换与单实例锁」、`docs/20260727-0632-同步功能复核记录-GPT-6.md`
