## 本轮核心交付

### 1. 同步预览与差异比对算法模块化解耦（`sync_preview.js`）
- **纯函数抽离**：
  - 新建 [`apps/codex-tauri/src/sync_preview.js`](../apps/codex-tauri/src/sync_preview.js)，从 `main.js` 抽离全部同步比对与状态格式化纯算法，削减 `main.js` 约 160 行内联代码。
  - `calculateSyncPayloadDiff`：纯内存比对本地快照与合并产物，精准计算账号新增、移除、字段级修改以及文件夹/通行密钥净增减。
  - `summarizeSyncAccountDiff`：生成账号差异摘要行（支持自定义展示上限 `limit` 与省略计数 `omitted`），严格只输出修改字段的语义标签，**绝不泄露密码、密钥或备注内容**。
  - `previewRecordKey`：按优先级对齐 CRDT 合并身份（`recordId` > `id` > `accountId` > `fallback`），避免永久删除墓碑在比对时被误算为新增。
  - `formatSyncPushState`：对齐同步报告全部状态组合（`dryRun`、`applied && pushed` 含上传/一致计数、`applied && !pushed && pendingRetry`、`!applied && ok`）。
  - `formatSyncDecisionSummaryLines`：格式化裁决摘要说明、模式名称与安全检查状态诊断。
  - `overwriteWarningText`：区分云端覆盖本地与本地覆盖云端两类互斥警示文本。
- **多端分发与静态门禁适配**：
  - 更新 `prepare-dist.mjs` 与 `sync-web-ui.mjs`，确保 `sync_preview.js` 自动同步至 `apps/extension_chrome_web/` 与 `dist/`。
