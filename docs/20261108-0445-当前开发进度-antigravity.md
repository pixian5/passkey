## 本轮核心交付

### 1. 实体排序与列表位移算法抽离（`vault_filters.js` 扩展）
- **纯函数抽象**：
  - `moveIdInList(ids, sourceId, targetId, before)`：纯算法计算有序列表（文件夹/账号拖拽排序）的相对位移，支持向前、向后插入及边界截断，位置未变或目标无效时纯净返回 `null`。
  - `sortAccountsList(list, { mode, regularOrderIds })`：实现 `usernameAZ`、`siteAZ` 及 `default` 模式。在 `default` 模式下精确遵循：置顶账号优先（按 `pinnedSortOrder` 排序）→ 未置顶账号按 `regularOrderIds` 显式顺位 → 按更新时间 `updatedAtMs` 倒序 → 稳定唯一键兜底。
  - `filterPasskeysForAccount(account, passkeys)`：解耦账号与通行密钥关联算法，优先凭据 ID（`credentialIdB64u`）关联，次级匹配 RP ID 与站点域名，严格剔除软删除及永久删除墓碑。
  - `findAccountByAnyId(accounts, id)`：基于 `sameId` 大小写不敏感比对，统一适配 `recordId`、`id` 与历史 `accountId`。
- **UI 主脚本精简**：
  - `apps/codex-tauri/src/main.js` 引入上述纯函数，去除内联的重复比较和位移逻辑，代码结构更加精炼。
