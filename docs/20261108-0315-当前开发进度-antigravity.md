## 本轮完成项

### 1. TOTP 与 Google Authenticator 迁移解析核心模块化（totp.js）
- **巨石代码瘦身**：将原本堆叠在 4,600+ 行 `apps/codex-tauri/src/main.js` 内部的近 200 行算法与格式解析逻辑剥离为纯原生 ES 模块 [`apps/codex-tauri/src/totp.js`](file:///Users/x/code/pass/apps/codex-tauri/src/totp.js)。
- **核心算法独立封装**：
  - RFC 4648 Base32 解码（`base32Decode`）与编码（`base32Encode`）；
  - RFC 4226 HOTP 计算（`hotp`）与 RFC 6238 TOTP 实时验证码生成（`totpCode`，含 30 秒步长与剩余秒数计算）；
  - `otpauth://totp/...` 规范 URI 深度解析（`parseOtpAuthUri`），支持站点名、用户名、发行方解析与容错；
  - Google Authenticator 迁移协议解析（`googleMigrationEntries`），支持 Protobuf Varint 与有线格式解码（Wire Types 0/2），提取多账号种子并转换为标准 Base32 密钥。
- **纯计算与 DOM 隔离**：`totp.js` 不依赖任何 DOM 节点或 Canvas 模拟，纯基于 WebCrypto API（`crypto.subtle`），可在 Node.js、浏览器扩展 Service Worker 与前端页面无缝同构运行。
- **构建同步管线升级**：更新 `prepare-dist.mjs` 与 `sync-web-ui.mjs`，确保 `totp.js` 自动分发至 `dist/` 与 Chrome Web 扩展目录。
- **标准自动化单测扩充**：在 [`apps/extension_shared/tests/totp.test.mjs`](file:///Users/x/code/pass/apps/extension_shared/tests/totp.test.mjs) 新增 8 项自动化测试，覆盖 RFC 6238 官方标准测试向量（附录 B 黄金用例）、Base32 往返、URI 解析与 Google Migration Protobuf 解码，扩展层测试用例数扩充至 **217 项全绿**。
