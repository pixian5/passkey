## 1. 双端并发 CAS 与密钥轮换混沌测试套件落地

针对此前积压的“两台设备同一主源并发/覆盖/密钥轮换实测”技术债务，本轮在 `apps/sync_server_ubuntu/tests/test_concurrent_chaos.py` 实现了多端并发混沌模拟测试：
- **并发写冲突与 412 捕获**：模拟 Client A 与 Client B 基于同一初始 revision 并发提交，通过多线程 Barrier 保证请求并发命中服务端，精准验证 200 成功与 412 拒绝的分歧；
- **自动拉取合并闭环**：验证触发 412 的客户端自动拉取最新远端快照，在本地执行字段级合并后携带最新 ETag 重试，最终双端稳定收敛无数据丢失；
- **密钥轮换一致性**：模拟 Client A 触发主密钥轮换（Key 1 -> Key 2）的同时 Client B 提交旧密钥载荷，验证 Client B 捕获 412 并基于新密钥重构合并载荷提交的全流程；
- **幂等重放与审计**：验证相同 Idempotency-Key 的重放不会在版本历史中产生冗余副本；缺少 If-Match 的覆盖写被 428 Precondition Required 严格拦截。
