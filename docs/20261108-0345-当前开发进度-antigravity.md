## 本轮工作内容

### 1. 响应式保密库 Store 与状态模型解耦（`store.js`）
- **路径**：[`apps/codex-tauri/src/store.js`](../apps/codex-tauri/src/store.js)
- **核心组件**：
  1. `createEmptyState()` / `normalizeAppState(raw)`：定义标准空保密库状态，提供保密库数据类型的确定性归一化与防空保护。
  2. `createDefaultLockState()` / `normalizeLockState(raw)`：封装锁定状态与空闲策略（`enabled`, `locked`, `idleLockMinutes`, `preferBiometrics` 等），防范外部数据类型漂移。
  3. `createDefaultUiPrefs()` / `normalizeUiPrefs(raw)`：统一管理字体、字号、全局明文开关、自动同步间隔与 WebDAV 参数。
  4. `SelectionModel`：面向对象的账号选择管理器，封装单选（`selectOnly`）、反选（`toggle`）、连续范围选择（`selectRange`）、全选（`selectAll`）、无效账号安全修剪（`prune`）、状态清理（`clear`）与成员查询（`has`, `ids`, `count`）。
  5. `VaultStore`：具备事件发布订阅能力的响应式状态管理器，支持 `state-change`, `lock-change`, `filter-change`, `prefs-change`, `state-cleared` 等多维度切面通知。

### 2. 交互层与敏感数据擦除彻底统一
- 重构 [`apps/codex-tauri/src/main.js`](../apps/codex-tauri/src/main.js)：

  - `doLockNow` 与空闲超时锁定统一调用 `createEmptyState()` 和 `selection.clear()`，杜绝私密数据残留在前端内存。
  - 账号列表多选逻辑完全委托给 `SelectionModel`，保证 Shift+Click 跨选、Cmd/Ctrl+A 全选与单选行为在三端绝对一致。
