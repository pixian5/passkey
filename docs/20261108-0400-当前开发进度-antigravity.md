## 本轮工作内容

### 1. 模态弹窗与确认框管理器解耦（`dialog.js`）
- **路径**：[`apps/codex-tauri/src/dialog.js`](../apps/codex-tauri/src/dialog.js)
- **核心能力**：
  1. `openModal(el)` / `closeModal(el)` / `isModalOpen(el)` / `hasAnyOpenModal(root)`：统一全端弹窗隐藏与显式属性管理，保证 `hidden` 属性和布尔属性双向同步。
  2. `setButtonBusy(button, busyText)`：纯函数式高阶工具，统一管理全端 30+ 处异步按钮的禁用态、`is-busy` 样式切换与幂等恢复回调。
  3. `ConfirmationDialog`：基于 Promise 的异步模态确认框基类，提供打开、确认、取消、被后续请求覆盖自动清理的生命周期闭环。
  4. `ActionConfirmDialog`：通用操作确认框模型，统一管理操作标题、确认提示文案、主确认/危险按钮切换与焦点自聚焦。
  5. `ModalEscapeHandler`：多级 ESC 键退出分发器，按优先级依次关闭二级确认弹窗、一级编辑设置弹窗与右键菜单。
