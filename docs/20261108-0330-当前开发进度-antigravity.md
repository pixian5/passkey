## 本轮工作内容

### 1. Web 表现层通用工具模块化（`ui_utils.js`）
- **路径**：[`apps/codex-tauri/src/ui_utils.js`](../apps/codex-tauri/src/ui_utils.js)
- **职责**：
  1. `inferToastLevel(text)`：根据提示文案特征智能推断 Toast 级别（`error` / `warn` / `info`），统一全端反馈语义。
  2. `escapeHtml(text)`：高防 XSS 转义函数（`&`, `<`, `>`, `"`, `'`）。
  3. `isApplePlatform(platformString, userAgent)`：统一判断 macOS / iOS 平台。
  4. `isMultiSelectModifier(event, platformString, userAgent)`：多选修饰键判定（Mac 下为 Meta 键，Windows/Linux 下为 Ctrl 键）。
  5. `compareOptionalOrder(a, b)`：安全比较可选排序索引（正数、undefined/null 降序处理）。
- **解耦效果**：消除了 `main.js` 内部散落的平台嗅探与转义逻辑，零 DOM 耦合，纯函数可测。

### 2. 保密库数据检索与过滤逻辑模块化（`vault_filters.js`）
- **路径**：[`apps/codex-tauri/src/vault_filters.js`](../apps/codex-tauri/src/vault_filters.js)
- **职责**：
  1. `accountRecordId(account)` / `accountKey(account)`：统一账号唯一凭证键推断。
  2. `isPinnedAccount(account)`：置顶状态检测。
  3. `hasTotp(account)` / `hasPasskey(account)`：双因子与通行密钥能力判定。
  4. `folderIdsOf(account)`：文件夹归属安全提取（兼容 `folderId` 标量与 `folderIds` 数组）。
  5. `matchesSearchQuery(account, query)`：多字段模糊搜索匹配（标题、用户名、站点、备注、恢复码等）。
- **解耦效果**：将保密库列表筛选、搜索匹配、能力分类逻辑从主事件驱动层剥离，大幅精简 `main.js` 代码体积。
