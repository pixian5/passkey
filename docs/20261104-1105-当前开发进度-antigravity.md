## 1. Python SQLite 连接资源告警消除

在 Python 3.12+ 运行单元测试时，`sqlite3.Connection` 若在未调用 `close()` 的情况下被垃圾回收，会产生 `ResourceWarning: unclosed database in <sqlite3.Connection object>`。本次排查发现 `with sqlite3.connect(...) as conn:` 仅管理事务上下文，并不自动调用 `close()`，导致测试与脚本工具中存在句柄悬挂。

**修复范围**：
- `apps/sync_server_ubuntu/tests/test_server.py`：
  - `test_legacy_revision_columns_are_backfilled_per_scope`：引入 `contextlib.closing` 确保只读查询后连接安全关闭；
  - `test_startup_removes_legacy_plaintext_payload`：引入 `contextlib.closing` 并补全 `connection.commit()`，彻底关闭连接并保障事务正确提交。
- `scripts/verify_local_backup.py`：对 `verify` 方法内的只读 SQLite 连接使用 `contextlib.closing` 包装。
- `scripts/backup_and_verify_local.py`：对 `create_backup` 执行 `VACUUM INTO` 时的连接使用 `contextlib.closing` 包装。
- `scripts/tests/test_verify_local_backup.py`：对测试夹具临时数据库的构建与连接全部收归 `contextlib.closing` 管理。
